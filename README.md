# Python & Libraries Practice 🐍

Is repository mein meri daily Python learning, basic to advanced concepts practice, aur practice problems ke codes save hain.

---

### 📚 Covered Topics & Code
- **Python Fundamentals:** Variables, Data Types, Operators
- **Control Flow:** If-Else conditions, For Loops, While Loops
- **Functions & Modules:** Functions creation, built-in functions, parameters
- **Data Structures:** Lists, Tuples, Dictionaries, Sets
* **NumPy**: N-dimensional arrays, matrix operations, indexing, slicing, broadcasting, and vector math
* **Pandas**: Series, DataFrames, data cleaning, filtering, grouping, merging, and CSV/Excel file handling
* **Matplotlib**: 2D plotting, line charts, bar plots, scatter plots, histograms, and figure customization
* **Seaborn**: Statistical data visualization, heatmaps, pairplots, box plots, and advanced color palettes
* **Practice Problems**: Logic building, problem-solving scripts, and library-based assignment exercises
